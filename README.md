# Commercial Sales, Profitability & Supply Chain Performance Analysis

### Project Overview
An end-to-end data analytics project focused on analyzing commercial sales, profitability, and supply chain performance using **MySQL and Microsoft Excel**.

This project transforms raw supply chain data into meaningful business insights through SQL-based data preparation, business analysis, and an interactive Excel dashboard.

### Project Objectives
- Analyze overall sales and profitability performance.
- Identify sales trends across different time periods.
- Evaluate product category and market performance.
- Analyze shipping modes and delivery status.
- Build an interactive dashboard to support business decision-making.

### Tools & Technologies
- **MySQL** – Data cleaning, transformation, and business analysis.
- **Microsoft Excel** – Data analysis, PivotTables, charts, slicers, and dashboard development.
- **SQL** – Data querying and business performance analysis.

### Dataset
**Dataset:** DataCo Smart Supply Chain Dataset

- Original records: 180,519
- Cleaned dataset: 33 columns
- Data includes sales, orders, customers, products, shipping, and delivery information.

### Project Workflow
1. Imported and prepared the raw dataset in MySQL.
2. Cleaned and transformed the data.
3. Performed SQL-based business analysis.
4. Exported the cleaned data for Excel analysis.
5. Created PivotTables and interactive visualizations.
6. Developed an Executive Dashboard with dynamic filters.

### Key Performance Indicators (KPIs)
- Total Net Sales
- Total Profit
- Total Orders
- Total Customers

### Dashboard Features
- Monthly Sales & Profit Trend
- Category Performance
- Market Sales Contribution
- Shipping Mode Performance
- Delivery Status Overview
- Interactive Market and Customer Segment slicers
- Year-based timeline filter

### Project Structure
- `SQL/` – SQL scripts for data preparation and business analysis.
- `Excel/` – Interactive Excel dashboard workbook.
- `Dashboard_Screenshot/` – Executive Dashboard preview.
- `Documentation/` – Detailed project documentation.

### Business Value
This project demonstrates how SQL and Excel can be used together to transform raw commercial data into structured analysis and interactive business reporting, helping stakeholders understand sales performance, profitability, and supply chain operations.

### Conclusion
The project showcases an end-to-end data analytics workflow, combining SQL data preparation and business analysis with Excel dashboard development.
