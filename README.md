\# Commercial Sales, Profitability \& Supply Chain Performance Analysis



\## Project Overview

An end-to-end data analytics project focused on commercial sales, profitability, and supply chain performance using MySQL and Microsoft Excel.



\## Tools \& Technologies

\- MySQL

\- Microsoft Excel

\- SQL



\## Dataset

\*\*DataCo Smart Supply Chain Dataset\*\*

\- Original records: 180,519

\- Cleaned dataset: 33 columns



\## Project Objectives

\- Analyze sales and profitability.

\- Identify monthly sales trends.

\- Evaluate category and market performance.

\- Analyze shipping and delivery performance.

\- Develop an interactive Excel dashboard.



\## Key Performance Indicators

\- Total Net Sales

\- Total Profit

\- Total Orders

\- Total Customers



\## Dashboard Features

\- Monthly Sales \& Profit Trend

\- Category Performance

\- Market Sales Contribution

\- Shipping Mode Performance

\- Delivery Status Overview

\- Interactive slicers and timeline



\## Project Workflow

1\. Data cleaning and preparation using MySQL.

2\. SQL-based business analysis.

3\. Export of cleaned data.

4\. Excel PivotTable analysis.

5\. Interactive dashboard development.



\## Project Structure

\- `SQL/` – SQL scripts for data preparation and business analysis.

\- `Excel/` – Interactive Excel dashboard.

\- `Dashboard\_Screenshot/` – Dashboard preview.

\- `Documentation/` – Project documentation.



\## Business Value

This project demonstrates how SQL and Excel can transform raw commercial data into meaningful business insights and interactive reports.



\## Conclusion

An end-to-end analytics project combining SQL data preparation and business analysis with Excel dashboard development.
